When the daily message limit is reached the assistant switches itself off until midnight. The limit is set with ASSISTANT_DAILY_LIMIT.

How the switch works

The assistant runs only when all of these are true:
  1. ASSISTANT_ENABLED=true in the server .env (emergency kill switch, needs a restart)
  2. An API key is set, or ASSISTANT_PROVIDER=mock
  3. The runtime toggle on this page is on (no restart)
  4. Today's message limit has not been reached
The server enforces this on every request. When off, POST /api/assistant/chat returns 503 even if called directly.
